🧾 영수증장부

개인정보처리방침

시행일: 2026년 9월 1일

영수증장부(이하 “서비스”)는 이용자가 촬영한 영수증을 이용자 본인의 구글 드라이브에 올리고, 이용자 본인의 구글 스프레드시트에 정리해 주는 자료 정리 도구입니다. 서비스는 이용자의 개인정보를 소중히 다루며, 아래와 같이 처리 방침을 안내합니다.

1. 수집하는 정보

구글 계정 정보이름, 이메일 주소, 프로필 이미지 — 로그인한 이용자를 식별하기 위해 사용합니다.
영수증 이미지·PDF이용자가 직접 촬영하거나 선택해 올린 파일입니다.
영수증에서 추출한 거래 정보거래일자, 상호, 금액, 분류, 카드사, 마스킹된 카드번호, 승인번호 등 장부 작성에 필요한 항목입니다.

서비스는 주민등록번호, 계좌 비밀번호, 카드 전체 번호 등 민감한 금융 인증정보를 수집하지 않습니다.

2. 구글 사용자 데이터 접근 범위와 목적

서비스는 구글 로그인 시 아래 권한을 요청하며, 각 권한은 명시된 목적으로만 사용됩니다.

구글 드라이브이용자가 지정한 영수증 보관 폴더에 파일을 올리고, 처리 후 월별 폴더로 정리하기 위해 사용합니다.
구글 스프레드시트이용자의 장부 시트에 거래 내역을 기록하고, 앱 화면에서 내역·집계를 보여주며, 확인 상태를 갱신하기 위해 사용합니다.

서비스는 위 목적과 무관한 파일이나 문서에 접근하지 않습니다.

3. 정보의 저장 위치

이용자의 자료는 이용자 본인의 구글 계정에 저장됩니다. 영수증 이미지는 이용자의 구글 드라이브에, 거래 내역은 이용자의 구글 스프레드시트에 기록됩니다. 서비스는 이용자의 영수증이나 장부 자료를 별도의 자체 서버에 저장하지 않습니다.

4. 자동 판독을 위한 외부 처리

영수증에서 금액·상호·일자 등을 읽어내기 위해 업로드된 이미지가 구글 Gemini API로 전송되어 처리됩니다. 이는 판독 목적에 한정되며, 판독이 끝나면 결과 값만 장부에 기록됩니다. 해당 처리는 구글의 API 정책에 따릅니다.

5. 제3자 제공

서비스는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 광고 목적의 이용이나 프로파일링도 하지 않습니다. 다만 법령에 따라 수사기관 등이 적법한 절차로 요구하는 경우에는 관련 법령을 따릅니다.

6. 구글 API 서비스 사용자 데이터 정책 준수

서비스가 구글 API로부터 받은 정보의 사용 및 다른 앱으로의 전송은, 제한적 사용 요건(Limited Use)을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

7. 보관 및 삭제

  • 영수증 파일과 장부 기록은 이용자 본인의 구글 계정에 있으므로, 이용자가 직접 삭제할 수 있습니다.
  • 서비스 이용을 중단하려면 연동을 해제하면 됩니다. 구글 계정 → 보안 → 타사 앱 및 서비스에서 이 앱의 액세스 권한을 언제든 회수할 수 있습니다.
  • 연동을 해제해도 이미 이용자의 드라이브·시트에 저장된 자료는 그대로 남습니다. 삭제를 원하면 이용자가 직접 지우면 됩니다.

8. 보호를 위한 조치

  • 서비스는 이용자의 구글 비밀번호를 알지 못하며 저장하지도 않습니다. 구글이 발급한 접근 토큰만 사용합니다.
  • 연결 정보는 암호화되어 보관되며, 통신은 HTTPS로 이루어집니다.

9. 아동의 개인정보

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

10. 방침의 변경

내용이 변경되는 경우 이 페이지에 수정된 방침과 시행일을 게시합니다.
